added it + `overflow:clip`. `.fields`/`fieldset` grid-template-columns overrides inside the
767.98px media query silently lost to the base rule in Chromium (confirmed via CSSOM + inline-
style probes) — switched both to Flexbox (`flex-basis`), which resolved it.
