# U3 — Motion core + brand ribbons

`scripts/motion/{core,countup,marquee,pause,main}.ts` (eases, onEnter contract, loop watcher,
count-up prep, N-copy marquee + velocity coupling, pause toggle binding). `global.css`: `ch-*`
keyframes (rot/bob/spin/mq), marquee layout + reduced-motion/paused CSS, `tab-hidden` loop pause.
`Ribbons.astro`: crossing bars, hidden `<ul>` of 17 brands, M-05 clip-path tape pull. Mounted in
`index.astro` after the hero stub; `main.ts` mounted once at the end of `Base.astro` body.

**Checks**
a. `npm run build` exit 0 (only Node type-stripping notice); `npx astro check` 0/0/0;
   `grep -rn "vm[A-Z]" src` 0 hits.
b. `qa.mjs U3` / `--nojs` / `--reduced`: all 9 runs `ok`, `consoleErrors=0`.
c. Seam (Playwright, 1440×900 + 1920×1080): bar-2 (ribbon 2) byte-identical PASS both widths;
   bar-1 (ribbon 1) FAIL both widths (diff 57401B @1440, 83725B @1920) — `firstSet.offsetWidth`
   rounds to an integer px (e.g. 1926) while the actual rendered set width is fractional
   (1924.30px); `--shift` inherits that ~1.7px error. Tail PASS all 4 (bar-1/bar-2 × 2 widths).
d. `--nojs` 1440/390: both ribbons render with full text, tilted, crossing. `--reduced` 1440:
   tilts kept (−4°/+3°), one static centred set per bar, no motion.
e. Footer `[data-pause-toggle]` has no `data-label-on`/`data-label-off` (text stays "Pause the
   party" always) — flagging per brief, Footer.astro untouched. Click → paused + 0 running
   `.mq-track` anims; reload → still paused, `aria-pressed=true`; click → resumes. All 8 PASS.
f. Fast wheel scroll (3000px/100px steps): `playbackRate` 1.546 during, 1.0 one second after.

**Deviations / doubts**
- Check c bar-1 fails as built literally to spec (`setW = firstSet.offsetWidth`); brief's check
  text anticipates a non-identical result ("if not, report the differing byte count"), so
  reported rather than silently swapping to `getBoundingClientRect().width` (different shape).
- `.ribbons[data-m="tape"]` is the `onEnter` trigger/`.is-in` element per the entry contract
  (selector `.ribbons[data-m="tape"]:not(.is-in) .bar-1`); "band" in spec prose read as the
  section, not the literal inner `.band` div (which holds height/overflow only).
